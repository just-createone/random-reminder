## 十二、问题优先级

### P0：阻塞

影响核心功能，必须立即处理：

- 页面无法打开
- 主要按钮完全无法使用
- 数据无法保存
- 手机端完全无法操作
- 页面严重错位
- 用户无法进入核心页面

### P1：严重

明显影响主要使用流程：

- 删除确认框无法关闭
- 重要按钮被遮挡
- 长文本破坏页面
- 主要导航入口缺失
- 通知权限流程无法完成
- 保存成功但页面显示错误状态

### P2：一般

不阻塞功能，但影响体验：

- 间距不统一
- 部分尺寸下布局不理想
- 提示显示时间不合理
- 文案不够清楚
- 页面留白比例不协调

### P3：轻微

视觉和细节优化：

- 图标细节
- 动画效果
- 次要颜色调整
- 非关键文字优化
- 轻微对齐问题
